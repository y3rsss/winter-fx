winter-fx

Snow for any website. It falls over the page without getting in the way.

Snow

  • Clicks go through the snow to the page underneath.
    Clicks: 0
  • Takes any CSS color, including variables and light-dark(), and follows theme changes right away.
  • Draws at the screen's pixel density, up to 2x, so flakes stay sharp.
  • Fills the new shape when the window is resized or a phone is rotated.
  • Stays in place while the page scrolls.
  • Stops when the visitor turns on reduced motion, and comes back when they turn it off.
  • Falls at the same speed on 60 Hz and 120 Hz screens.
  • Fades in when it starts.
